## 🇺🇸 English

### 🍽️ NutriChef App

**NutriChef** is an Android application developed in **Kotlin** to help users explore and understand the nutritional value of various dishes.  
With a simple and intuitive interface, users can browse a variety of meals, check calories, proteins, carbohydrates, fats, and more.  
The goal is to make healthy eating easier and more engaging.

### 🛠️ Tools and Technologies Used

- **Kotlin** 💻 — Main programming language  
- **Jetpack Compose** 🎨 — Modern UI toolkit for Android  
- **Firebase** 🔥 — Backend services for authentication and database  

## 🇧🇷 Português

### 🍽️ Aplicativo NutriChef

**NutriChef** é um aplicativo Android desenvolvido em **Kotlin** que ajuda os usuários a explorar e compreender o valor nutricional de diversos pratos.  
Com uma interface simples e intuitiva, é possível navegar entre diferentes refeições, verificar calorias, proteínas, carboidratos, gorduras e muito mais.  
O objetivo é tornar a alimentação saudável mais prática e envolvente.

### 🛠️ Ferramentas e Tecnologias Utilizadas

- **Kotlin** 💻 — Linguagem principal do projeto  
- **Jetpack Compose** 🎨 — Toolkit moderno de UI para Android  
- **Firebase** 🔥 — Serviços de backend para autenticação e banco de dados
